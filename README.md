# Скиллы безопасности для ИИ-ботов

Три скилла для Claude Code (и других агентов, которые читают инструкции в Markdown), чтобы проверять чат-ботов и RAG-ботов до запуска. Сделано для небольших ботов малого бизнеса: ответы клиентам, запись, заявки.

Исходная мысль: надёжного способа предотвратить промпт-инъекции сейчас нет. Поэтому защищает не «правильный промпт», а устройство: что бот знает, что видит и что может сделать.

| Скилл | Когда использовать | Что получите |
|---|---|---|
| [`bot-trap-eval`](bot-trap-eval/SKILL.md) | Перед запуском и после каждой смены промпта, модели или материалов | Набор из ~12 ловушек под ваш бизнес, прогон и отчёт OK / частично / провал |
| [`rag-corpus-guard`](rag-corpus-guard/SKILL.md) | Перед загрузкой или обновлением материалов | Отчёт сканера: скрытый текст, фразы-инструкции, невидимые символы, персональные данные |
| [`agent-access-review`](agent-access-review/SKILL.md) | При проектировании агента и добавлении инструментов | Таблица доступа, опасные сочетания, что убрать или сузить |

## Установка (Claude Code)
Скопируйте папки в `.claude/skills/` проекта или в `~/.claude/skills/`:

```bash
git clone https://github.com/whaleflow13/whaleflow-safety-skills.git ai-safety-skills
cp -r ai-safety-skills/bot-trap-eval ai-safety-skills/rag-corpus-guard ai-safety-skills/agent-access-review .claude/skills/
```

Дальше просто попросите: «проверь бота на ловушки», «проверь материалы корпуса перед загрузкой», «сделай ревью доступа агента».

Сканер из `rag-corpus-guard` работает и сам по себе, нужен только Python 3.10+:

```bash
python rag-corpus-guard/scripts/scan_corpus.py corpora/my-bot --domain example.ru --report report.md
```

## Ограничения
- Это проверки на типовые ошибки, а не аудит безопасности. Чистый отчёт не значит «взломать нельзя».
- Проверяйте только своих ботов или ботов, владелец которых дал согласие.
